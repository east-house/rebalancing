# 라오어 VR 적립식 화면

서비스 메뉴의 **VR 적립식**, 또는 `/vr`에서 접근합니다.

## 계산 기준과 출처

모두 라오어 카페 원문이 아닌 2차 자료이며, 원문과 대조하지 않았습니다.

| 항목 | 규칙 | 출처 |
|---|---|---|
| V 공식 · 기본 | `V + Pool/G + 적립금` | quantstack.app/vr |
| V 공식 · 실력공식(옵션) | `V + ROUND(Pool/G,3) + ROUND((직전 마감 평가금 − V)/ROUND(2√G,3),3) + 적립금` | 시트 v5.0.4 적립식!F10 |
| 밴드 | `ROUNDDOWN(V × 0.85, 2)`, `ROUNDDOWN(V × 1.15, 2)` | 시트 적립식!G9·H9 |
| G | `기준 G + ROUNDUP(주차/52) − 1` (52주마다 +1) | 시트 Setting!L45 |
| Pool 사용 한도 | `MAX(10%, 시작 한도 − 5%p × (ROUNDUP((주차+2)/26) − 1))` | 시트 Setting!L46 |
| 매수 주문표 | k번째 = V최소 ÷ (보유+k−1), 1주씩. 매수 후 Pool ≥ 시작일 Pool×(1−한도)이고 단가 ≥ 직전 마감 종가×60%인 줄까지 + 1줄 | 시트 주문!C10·J10 |
| 매도 주문표 | k번째 = V최대 ÷ (보유−k+1), 1주씩, 1주 남을 때까지 | 시트 주문!F10·K10 |
| V0 | 보유 수량 × 0주차 마감 종가 | 시트 적립식!K9 |

시트: "dj_VR 5.0.4 by.글로벌커머스_실력공식(10만원으로2억).xlsx". Pool은 적립 전 금액(직전 사이클 마감 Pool)이고, 주차(Week) = 사이클 번호 × 2입니다.

이 화면에서 정한 부분:
- 시트는 주문 단가를 반올림하지 않습니다. 여기서는 매수가를 센트 단위로 내리고 매도가는 올립니다.
- 추가 1줄은 Pool이 음수가 되면 만들지 않습니다.
- 수수료는 반영하지 않습니다.
- 0일차 매수 제안 비율(P/V 0.15)은 quantstack 거치식 초기 세팅의 G 10 값입니다. 적립식 초기 비율은 원 방법론과 시트 모두에 없습니다.

## 이어가기

1. 이어가기 (평단가로), 기본 탭: 현재 주차, 보유 수량, 평단가, 2주 적립금만 입력합니다.
   - 직전 마감 종가는 사이트 가격 API(`/api/market-data/history/US/{종목}`)에서 사이클 시작일 이전 마지막 종가로 자동 입력합니다. 직접 고칠 수 있습니다.
   - 현재 현금 Pool은 선택 항목이며 기본값은 0입니다.
   - 직전 V 대체값은 둘 중 하나를 고릅니다: 평단가 기준(보유 × 평단가) 또는 평가금 기준(보유 × 직전 종가).
   - 이 대체값은 원 방법론이나 시트의 규칙이 아니라 이 화면의 근사입니다.
   - 홀수 주차는 다음 짝수 주차 사이클로 시작합니다.
2. 이어가기 (V를 알 때): 주차, 직전 V, 직전 마감 종가, 보유 수량, 적립 전 Pool을 입력합니다.
3. 새로 시작: 0일차 보유 수량, 마감 종가, Pool을 입력합니다. 첫 사이클(2주차)은 14일 뒤에 열립니다.
4. 사이클 시작일에 주문표를 보고 1주씩 지정가 잔량 주문을 겁니다.
5. 사이클 끝에 실제 보유 수량, 적립 전 Pool, 마감 종가를 입력해 마감합니다. 그러면 다음 사이클이 열립니다. 설정 변경은 다음 사이클부터 적용됩니다.
6. 기록은 브라우저 localStorage(`tm.vr-installment`, 스키마 v2)에만 저장됩니다. JSON 백업과 불러오기를 지원합니다.

## 범위 밖

거치식·인출식, 가격 자동 입력, 주문 전송, 체결 확인, 서버 저장.

## 검증

- 테스트는 시트의 2~20주차 V(5011.89 … 5452.905), 20주차 밴드(4634.96~6270.84), Pool 한도($647.18), 남길 Pool($215.73)을 재현합니다.
- 주문표도 시트와 같습니다: 매수 12줄, 매도 74줄.
- 실행: `npx vitest run src/features/vr src/RootApp.test.tsx`, `npm run build`
